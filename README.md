I design and build AI systems end to end: from the architecture and the data flow to the
model calls, evaluation and deployment. These days most of my work is LLM-based systems,
speech and vision pipelines. Based in Tashkent, Uzbekistan.

### What I work on

- **LLM systems.** Architecture around LLM APIs: structured classification, retrieval (RAG),
  prompt and schema design, and choosing the right model for each step.
- **Speech and vision pipelines.** Speech-to-text, face detection and recognition, real-time
  processing on ordinary hardware.
- **Measuring instead of guessing.** I compare models on latency, token use, cost and
  accuracy before committing to one.

### Featured project

**[SafeCamera](https://github.com/navruzbek1/safecamera)** locks a Windows PC when the owner
walks away, unlocks it by face, and blurs the screen when someone else looks at it. Local
processing with OpenCV (YuNet and SFace), tested, with CI.
